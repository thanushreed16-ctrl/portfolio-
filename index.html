01Ongoing · Team project

Hospital Delivery Robot

ROS 2 based autonomous mobile robot

Problem

Moving medicines and supplies around a hospital takes staff time and effort. This project builds an autonomous mobile robot to assist with internal deliveries.

Tech stack

  • ROS 2 Jazzy
  • Ubuntu 24.04
  • Gazebo
  • Nav2
  • SLAM
  • RViz 2
  • Python
  • Four-wheel chassis

How it works

  1. 1Four-wheel robot simulated in Gazebo
  2. 2SLAM-based mapping and localization
  3. 3Autonomous navigation with the Nav2 stack
  4. 4Python GUI integrated with ROS 2 to pick destinations (wards, ICU, pharmacy, lab) and monitor battery, speed mode and a storage leak sensor

My contribution

Worked with team members on ROS 2 setup, robot modelling, simulation, navigation and Python GUI integration.

Outcome

A simulated mobile robot that moves in Gazebo, maps with SLAM, navigates with Nav2 and is controlled through a ROS 2-integrated GUI. The full delivery workflow and physical robot are in progress.

Next: physical robot, real-world obstacle avoidance tests, multi-room delivery management.
